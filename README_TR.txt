MOOSHGF'S TORNADO MOD — Forge 1.20.1

ÖZELLİKLER
- /mooshgfstornado help
- /mooshgfstornado start normal [1-4]
- /mooshgfstornado start supercell [1-4]
- /mooshgfstornado capacity 1|2|3|4
- /mooshgfstornado stop
- /mooshgfstornado dominator 1|2|3|4

Kasırga görseli özel model değil, vanilla CLOUD ve (supercell için) ELECTRIC_SPARK parçacıklarından oluşur. SMOKE parçacığı kullanılmaz. Kasırga yakındaki canlıları/i̇temleri merkeze çeker ve yukarı iter. Dominator komutu farklı renkli bloklardan basit araç maketi kurar; gerçek sürülebilir araç değildir.

JAR OLUŞTURMA (Windows)
1. Java JDK 17 kur (Minecraft 1.20.1 Forge geliştirmesi için).
2. Resmî Forge sayfasından 1.20.1 MDK indir: https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html
3. MDK ZIP'ini boş bir klasöre çıkar.
4. Bu paketteki src klasörünü ve build.gradle dosyasını MDK klasörüne kopyala; mevcut dosyaların üstüne yaz.
5. CMD'yi o klasörde aç ve çalıştır: gradlew.bat build
6. JAR: build\libs\MooshGFsTornado-1.0.0.jar
7. JAR'ı Forge 1.20.1 profilinin .minecraft\mods klasörüne koy.

Not: Bu çalışma alanında Forge bağımlılıkları/Gradle dağıtımı indirilip derleme çalıştırılmadığı için hazır JAR olarak doğrulanmış değildir. Bu ZIP kaynak proje paketidir. Komutlar OP/permission level 2 gerektirir.
